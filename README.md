# HHC Job Tracker v1.3 – Office Sync Test

V1.3 keeps the V1.2 weekly workflow, carryover/archive behavior, Apple Maps directions, photos and PDF sharing.

## New for the test
- **Sync from Office** reads `dispatch.json` from the same GitHub Pages repository.
- The app also performs a best-effort background sync when opened.
- Office schedule/customer/equipment changes update local jobs.
- If a crew has already started/completed a job, field-entered techs, times, materials, notes, photos and completion status are preserved during later office syncs.
- Old V1.2 simulated demo-week jobs are removed when the first real office feed is received.

Upload the contents of this folder to the root of the existing GitHub Pages repo. Then upload the `dispatch.json` generated by HHC Office Dashboard v0.2 to the same root.
